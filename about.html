关于我们

项目简介

御图网是一个集随机文案与精美壁纸于一体的个人网站。每次刷新，都是一场与文字和画面的不期而遇。

功能说明

提供随机动漫壁纸与随机美女壁纸两种模式，搭配经典一言文案，支持一键复制文案。将鼠标移到时钟上，其右上角会出现刷新按钮，点击即可在 经典 / 数码 / 英文 / 霓虹 / 复古 / 衬线 / 像素 / 海报 / 渐变 / 金 / 手写 / 蓝调 / 翻页 / 描边 / 赛博 共 15 种视觉风格的时间样式间切换（每种风格的字体、字号、配色与排版均不同），选择会被自动记忆。开启纯净模式后，可全屏欣赏壁纸。
